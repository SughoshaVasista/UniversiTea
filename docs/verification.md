# Verification & Trust System Specification

## Philosophy: Popularity is Not Proof

UniversiTea separates discussion popularity (upvotes/downvotes) from factual truth. Content verification is determined through evidence evaluation, not crowd consensus.

## Verification Status Lifecycle

1. **⚪ UNVERIFIED:** Initial state for newly posted tea. No corroborating proof receipts attached yet.
2. **🔵 CHECKING:** Active receipt evaluation or automated source domain checking in progress.
3. **🟡 LIKELY:** Supported by credible secondary sources or consistent corroborating receipts.
4. **🟢 VERIFIED:** Confirmed through official college domain links (`.edu`/`.ac.in`), official announcements, or verified primary documents.
5. **🟠 DISPUTED:** Contradictory evidence or conflicting receipts submitted by community members.
6. **🔴 FALSE:** Debunked by official evidence or verified counter-proof.
